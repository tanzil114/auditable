Common questions

A page shows "Changed since approval" but I did not change anything. Any edit that alters the page body changes the content hash — including edits made by automation, macros whose stored markup changes, or a bulk find-and-replace. Open the page history to see the version that triggered it. Re-approving records a fresh hash against the current version.

Line-ending or whitespace changes do not trigger it. Auditable normalises CRLF line endings and trailing whitespace before hashing, precisely so that saving a page without editing it does not raise a false alarm.

A document is overdue but nobody was notified. Review state is recalculated by a daily sweep and refreshed whenever the page is opened. If a document was enrolled today, its first sweep has not run yet.

I cannot approve — the button is missing. You are not a named approver on that control set. Approver rules are enforced on the server, not in the interface, so this cannot be bypassed by editing the page. Ask the control set owner to add you.

Uninstalling — will I lose my audit history? Yes. Uninstalling removes all app storage. Export an evidence pack before uninstalling if you need to retain the record.

Does the app change my pages? No. All Confluence permissions requested are read-only. The app never creates, edits or deletes content.
